01The problem

Prokudin-Gorskii photographed each scene three times in succession onto one tall glass plate — once through a blue filter, once green, once red. The Library of Congress scanned the plates as single grayscale images with the three exposures stacked BGR top to bottom.

Splitting the scan into thirds and stacking them gives a badly fringed image, because the exposures do not line up. The plate advanced between shots, and cutting at exactly one third of the height is only a guess — cathedral.jpg is 1024 pixels tall, which is not divisible by three.

The job: find the (x, y) translation bringing G onto B, and another bringing R onto B. B stays fixed as the anchor.

02Single-scale alignment

Exhaustive search over every integer displacement in a [-15, 15] window — 961 candidates — scored by L2 / Euclidean distance, implemented as mean squared error:

metric = lambda x, y: np.mean((x - y) ** 2)

The mean has the same argmin as sqrt(sum(...)) and keeps the numbers readable at any image size. Shifting is done with np.roll on both axes.

Scoring the full frame does not work: the plate margins and scan edges are high-contrast and near-identical across channels, so the metric lines up the borders instead of the picture. I crop a fixed interior margin off every channel first — 30px for JPEGs, 250px for TIFFs.

03Multi-scale pyramid

The TIFFs are ~10× wider and the misalignment scales with them: melons needs its red channel moved 179 pixels. Brute force would need ~160,000 candidates per channel over 8-megapixel arrays.

Instead, recurse down halving the image until a small window covers any plausible displacement, solve there, then on the way back up double the displacement at each level and refine.

def pyramid_align(anchor, other, ds):
    if other.shape[0] <= 32 or other.shape[1] <= 32:
        return align(anchor, other, ds, start=[0, 0])

    if other.shape[0] >= 100 or other.shape[1] >= 100:
        ds = np.arange(-2, 3)

    anchor_half = sk.transform.rescale(anchor, 0.5, anti_aliasing=True)
    other_half  = sk.transform.rescale(other,  0.5, anti_aliasing=True)

    _, best_ds_half = pyramid_align(anchor_half, other_half, ds)
    best_ds_start = [best_ds_half[0] * 2, best_ds_half[1] * 2]

    return align(anchor, other, ds, start=best_ds_start)

Two things carry the weight. The doubling is the algorithm — without it each level inherits a displacement in the wrong units and the estimate wanders instead of converging. The window shrinks as the image grows: once the inherited estimate is within a pixel, ±2 is enough, so each level costs 25 comparisons instead of 961. The full window is only used at the coarsest level.

The pyramid bottoms out at 32px. Recursing further measures noise, and that noise gets doubled all the way up. Every TIFF finishes in about two seconds; all seventeen run in under half a minute.

05Where it fails

emir is the one failure. Green aligns correctly at (24, 49); red ends up at (−492, 149). As described in the project spec, each image does not have the same brightness values — so an L2 comparison of raw intensities finds a false minimum.
