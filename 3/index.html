Part AThe Power of Flow Models

1.1Constructing Noisy Training Inputs

A clean image x1 is interpolated with Gaussian noise ε. t = 0 is pure noise and t = 1 is the clean image. One noise sample is reused for all three times.

xt = (1 − t) ε + t x1,    ε ~ 𝒩(0, I)

1.2Classical Denoising

Baseline without a learned model: divide by t to restore the image amplitude, then Gaussian blur. The blur σ with the lowest MSE out of {1, 2, 4, 8, 16} is shown.

x̂1blur = Gσ(xt / t)

1.3One-Step Denoising

One velocity prediction from PixNerd, extrapolated straight to t = 1, with the prompt "a high quality photo".

x̂1 = xt + (1 − t) vθ(xt, t, c)

1.4Visualizing Velocity

The update the model adds, (1 − t)v̂t, compared with the ground-truth update, plus a per-pixel RMS error map across RGB.

(1 − t) vgt = x1 − xt,    vgt = x1 − ε
Et = √( meanRGB[ (1 − t)(v̂t − vgt) ]2 )

1.5Iterative Denoising with Euler Sampling

Small steps along the predicted velocity, re-predicting after each step. Starting from the t = 0.50 input with h = 0.02 (25 updates).

xt+h = xt + h vθ(xt, t, c)

1.6Generating Images from Noise

Euler sampling from pure noise at t = 0 to t = 1 (50 updates) with "a high quality photo".

2.1Classifier-Free Guidance

Conditional and unconditional (empty prompt) velocities combined with guidance weight w = 7, same initial noises as 1.6.

vcfg = vc + w(vc − vu)

3.1Image-to-Image Editing

Noise an image to a starting time tstart, then Euler sample with CFG back to t = 1 using "a high quality photo". Starting times 0.02, 0.04, 0.06, 0.10, 0.14, 0.25, 0.50.

xtstart = (1 − tstart) ε + tstart x1

Hand-drawn and web images

3.2Text-Guided Image Editing

The same editing procedure and starting times, with a prompt describing the edit in place of "a high quality photo".

3.3Visual Anagrams

At each Euler step, average the CFG velocity for prompt p1 with the CFG velocity of the 180°-rotated image for prompt p2, rotated back.

v1 = CFG(xt, t, p1),    v2 = flip(CFG(flip(xt), t, p2)),    v = (v1 + v2) / 2

3.4Hybrid Images

At each Euler step, combine the low frequencies of one prompt's CFG velocity with the high frequencies of another's. Low-pass is a Gaussian blur with kernel size 265 and σ = 16.

v = flowpass(v1) + fhighpass(v2),    fhighpass(v) = v − flowpass(v)

Part BFlow Matching from Scratch

1.1Implementing the UNet

An unconditional UNet built from Conv, DownConv, UpConv, Flatten, Unflatten, and Concat operations, with two downsampling and two upsampling stages, skip connections, and hidden dimension D.

1.2Using the UNet to Train a Denoiser

The denoiser Dθ maps a noisy MNIST digit z to the clean digit x, trained with an L2 loss.

L = 𝔼z,x ‖Dθ(z) − x‖2,    z = x + σε,    ε ~ 𝒩(0, I)

1.2.1Training

σ = 0.5, D = 128, batch size 256, Adam with learning rate 1e-4, 5 epochs.

1.2.2Out-of-Distribution Testing

The σ = 0.5 denoiser applied to one test digit at noise levels it was not trained on.

1.2.3Denoising Pure Noise

The same training setup, but the input is pure noise z = ε with no image information.

Observed patterns: the generated outputs always look the same regardless of the input noise, a sort of digit-like blurry blob. This happens because the MSE loss forces the model to learn to output the "average" of the training images, which is the point that minimizes the sum of squared distances to the training images. So this output is like the average of all the digit images in the training set, hence why it is blurry. Also, since the input noise is independent of the target image, the model isn't given any hints as to which digit to produce, so it produces this same average digit every time.

2.1Adding Time Conditioning to UNet

Intermediate samples interpolate between noise x0 and a clean digit x1. The UNet uθ(xt, t) predicts the flow, with t injected through two FCBlocks that scale the Unflatten and first UpBlock outputs.

xt = (1 − t) x0 + t x1,    u(xt, t) = x1 − x0
L = 𝔼 ‖(x1 − x0) − uθ(xt, t)‖2

2.2Training the UNet

D = 64, batch size 64, Adam with initial learning rate 1e-2, exponential decay with γ = 0.11/10, 10 epochs.

2.3Sampling from the UNet

Euler integration from noise at t = 0 to t = 1 with T = 50 steps.

xt ← xt + 1⁄T uθ(xt, t)

2.4Adding Class-Conditioning to UNet

The digit class is added as a one-hot vector c through two more FCBlocks. c is set to the zero vector 10% of the time (puncond = 0.1) so the model also learns unconditional generation.

unflatten = c1 · unflatten + t1,    up1 = c2 · up1 + t2

2.5Training the UNet

Same setup as 2.2, with the class-conditioning vector and class dropout.

2.6Sampling from the UNet

Classifier-free guidance with γ = 5.0 and T = 300 steps, four samples of each digit.

u = uuncond + γ(ucond − uuncond),    xt ← xt + 1⁄T u

Without the learning rate scheduler

Getting rid of the learning rate scheduler: qualitatively, I was able to maintain performance without the learning rate scheduler. I did this by choosing the constant learning rate (1e-3) to be an order of magnitude smaller than the initial learning rate for the scheduler (1e-2). This is ideal because the scheduler starts at 1e-2 and decays towards 1e-3, so choosing a smaller learning rate for the entirety of training allows the model to converge to a minimum (potentially more slowly) without overshooting.
