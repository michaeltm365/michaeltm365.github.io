A.3Warp the Images

Inverse warping: the output bounding box comes from passing the four corners through H, then every output pixel is mapped back into the source image and sampled. Pixels that map outside the source are left empty.

p = H−1p′

Nearest neighbor takes the closest source pixel. Bilinear takes a weighted average of the four surrounding pixels, with Iij = I(xi, yj), x1 = ⌊x⌋, x2 = x1 + 1 (same for y), a = x − x1, and b = y − y1.

I(x, y) = (1−a)(1−b) I11 + a(1−b) I21 + (1−a)b I12 + ab I22

Rectification

Four corners of a rectangular object are mapped to an axis-aligned rectangle.

Nearest neighbor vs. bilinear

Bilinear interpolation qualitatively provides a smoother result by incorporating information from more neighboring pixels. This can be seen in its less jagged iages (e.g. on the side of the book) and slightly blurrier overall appearance compared to NN. But bilinear interpolation is also slightly more inefficient for this same reason (has to calculate and weigh more neighbors).

A.4Blend the Images into a Mosaic

Image 2 is the reference and image 1 is warped into its frame with bilinear interpolation. The two are combined with a weighted average, where each weight is the normalized distance transform of that image's mask.

wi = dist(Mi) / max dist(Mi),    mosaic = (w1I1 + w2I2) / (w1 + w2)

Procedure

My mosaicing procedure: I start by calculating the size of the final mosaic image with the compute_canvas_size function and creating two output arrays of that size (all zeros), so I can them map pixels from the source images onto them. Then, the pixels from the warped im1 are mapped onto canvas1, and the pixels from im2 are pasted onto canvas2 with an offset. Simultaenously, a binary mask is created for each canvas indicating whether or not a pixel was mapped to there. These masks are put through the distance_transform_edt function and normalized to get weights for each pixel. The resulting mask is such that pixels near the edges of each image and overlap regions get reduced weight, helping reduce seams. Then, the final mosaic is created by blending the two canvases according to the weighted masks using the feather_blend function.

At first, I started with 8 correspondences that were too close together, and noticed artifacts in the sparser parts of the image (see my 8 point mosaic). To resolve this, I upgraded to 16 correspondences, which provided a robust fit.

Part BFeature Matching for Autostitching

B.1Harris Corner Detection

Single-scale Harris corners on the 0.2× grayscale image, keeping local maxima of the corner strength that are above 1% of the image maximum and more than 20 pixels from the border. Adaptive non-maximal suppression then keeps the 500 points with the largest suppression radius, the distance to the nearest point that is sufficiently stronger (crobust = 0.9).

f(x, y) = det H(x, y) / tr H(x, y)
ri = minj |xi − xj|,    s.t. f(xi) < crobust f(xj)

B.2Feature Descriptor Extraction

Each ANMS corner gets an axis-aligned descriptor at a single scale. A 40×40 window centered on the corner is blurred and downsampled to 8×8 (sample spacing s = 5), then bias/gain normalized to zero mean and unit variance.

d = (p − μp) / σp

B.3Feature Matching

Descriptors are compared by sum of squared differences. Each descriptor in image A is paired with its nearest neighbor in image B, and the pair is kept only when the ratio of the 1-NN error to the 2-NN error is below 0.5.

e = Σ(da − db)2,    e1-NN / e2-NN < 0.5

I chose the 0.5 threshold by eyeballing Figure 6b in the paper: 0.5 permits a high fraction of the correct matches while only a low fraction of the incorrect matches

B.4RANSAC for Robust Homography

Four-point RANSAC. Each of N = 1000 iterations samples 4 random matches, fits a homography with computeH from Part A, and counts the matches that reproject within 3 pixels at 0.2× resolution. The largest inlier set is refit with least squares, and the result goes through the Part A bilinear warp and feathered blending.

‖Hpi − p′i‖ < ε,    ε = 3

I chose N=1000 iterations as an arbitrary large number, and the RANSAC threshold of 3 by searching through options of 1, 2, 3, and 5 and stopping after diminishing returns
