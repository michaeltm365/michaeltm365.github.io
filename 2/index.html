1.1Convolutions from Scratch

Convolution implemented two ways in numpy, with zero padding in both "same" and "full" modes, and the filter flipped before the sums.

def conv_four_loops(arr, ker, padding = "same"):
    ker = np.flip(ker)
    H, W = arr.shape
    kH, kW = ker.shape
    h_pad = (kH-1) // 2
    w_pad = (kW-1) // 2

    if padding == "same":
        pad_arr = np.pad(arr, pad_width = ((h_pad, h_pad), (w_pad, w_pad)))
    elif padding == "full":
        pad_arr = np.pad(arr, pad_width = ((kH-1,kH-1), (kW-1, kW-1)))

    out = np.zeros([pad_arr.shape[0] - kH + 1, pad_arr.shape[1] - kW + 1])
    for i_arr in range(out.shape[0]):
        for j_arr in range(out.shape[1]):
            out_val = 0
            for i_ker in range(kH):
                for j_ker in range(kW):
                    out_val += ker[i_ker, j_ker] * pad_arr[i_arr + i_ker, j_arr + j_ker]
            out[i_arr, j_arr] = out_val

    return out
def conv_two_loops(arr, ker, padding = "same"):
    ker = np.flip(ker)
    H, W = arr.shape
    kH, kW = ker.shape
    h_pad = (kH-1) // 2
    w_pad = (kW-1) // 2

    if padding == "same":
        pad_arr = np.pad(arr, pad_width = ((h_pad, h_pad), (w_pad, w_pad)))
    elif padding == "full":
        pad_arr = np.pad(arr, pad_width = ((kH-1,kH-1), (kW-1, kW-1)))
        
    out = np.zeros([pad_arr.shape[0] - kH + 1, pad_arr.shape[1] - kW + 1])
    for i_arr in range(out.shape[0]):
        for j_arr in range(out.shape[1]):
            out[i_arr, j_arr] = np.sum(ker * pad_arr[i_arr : i_arr + kH, j_arr : j_arr + kW])

    return out

2.1Image Sharpening

from part2_1.py

how the unsharp masked filter works: the Guassian blur filter G is a low pass filter: it removes high frequency details. Hence, doing high_freq = im - (G * im) leaves only the high frequency details of im. we can add high_freq back to im to emphasize the high frequencies of im, leaving a "sharpened" image.

Collapsed into the single kernel (1 + α)·δ − α·G. Against the three-step version this agrees to 1.78e−15 on the Taj and 1.55e−15 on the waterfall.

comment on blurring a sharp image, then trying to resharpen it: across different alphas, the mean absolute difference between the resharpened image and the original image remains high. This is because there is no way to recover the high frequencies that were completely zeroed out by the Guassian low pass filter, no matter how high alpha is. If you keep increasing alpha you are just amplifying noise.

2.3Gaussian and Laplacian Stacks

No downsampling — every level keeps the original dimensions. Level 0 of the Gaussian stack is the unblurred image; level i is the original convolved with a Gaussian of σi = σ0·2i−1. The Laplacian levels are successive differences, with the final Gaussian level kept as the residual.

def gauss_stack(im, sigma_0, levels):
    out = []
    out.append(im)
    for i in range(levels - 1):
        sigma_i = sigma_0 * (2 ** i)
        ker_i = gaussian_kernel(ksize=6 * sigma_i + 1, sigma=sigma_i)
        im_i = scipy.signal.convolve2d(im, ker_i, mode = "same")
        out.append(im_i)
    return np.array(out)
def laplace_stack(g_stack):
    out = []
    for i in range(len(g_stack) - 1):
        d = g_stack[i] - g_stack[i + 1]
        out.append(d)
    out.append(g_stack[-1])
    return np.array(out)

2.4Multiresolution Blending

Following the mask-based algorithm on page 230 of Burt & Adelson: build Laplacian stacks for both images, a Gaussian stack for the binary mask R, then combine level by level as LSl = GRl·LAl + (1 − GRl)·LBl and sum.

def blend(im1, im2, mask, sigma_0, levels):
    out_stack = []
    gr = gauss_stack(mask, sigma_0, levels)
    ga, la = gauss_laplace_stack(im1, sigma_0, levels)
    gb, lb = gauss_laplace_stack(im2, sigma_0, levels)

    # check if laplace is working (should be ~0)
    print(np.abs(sum(la) - im1).max())
    print(np.abs(sum(lb) - im2).max())

    for i in range(levels):
        avg = gr[i] * la[i] + (1 - gr[i]) * lb[i]
        out_stack.append(avg)
    out_stack = np.array(out_stack)
    return np.sum(out_stack, axis=0)

Both irregular blends use the same circular mask, built as a binary distance test and left hard-edged; the Gaussian stack does the softening.

def create_circle_mask(h, w, center=None, radius=None):
    cy, cx = center if center is not None else (h // 2, w // 2)
    r = radius if radius is not None else min(h, w) // 4
    rows, cols = np.ogrid[:h, :w]
    return ((rows - cy) ** 2 + (cols - cx) ** 2 <= r ** 2).astype(float)
